# 代码重构路线图

| 任务 | 目标 | 产出 |
| --- | --- | --- |
| 文件上传策略 | zip 新增同时补齐后端白名单、大小、MIME、压缩包安全策略。 | 文件策略服务与测试。 |

## 不建议立即做
- 不建议马上拆微服务；先完成模块内边界、状态事实源和测试基线。
- 不建议删除疑似旧表/旧代码；先冻结写入、归档和观测。
- 不建议用纯前端限制解决文件类型和权限问题。
