## 前端需求反推
- `ui/features` 更接近业务页面/功能入口。
- `ui/shared` 和 `packages` 更接近跨功能组件、工具、富文本、媒体、日期、上传、翻译等基础能力。
- Rails 页面、React feature、GraphQL/REST API 混合存在，前端重构时需要先确认每个 feature 的后端入口和权限上下文。
