# 权限与角色需求反推

## 角色模型推断

| 角色 | 反向需求 | 证据等级 |
| --- | --- | --- |
| 匿名用户 | 可访问登录、注册、公开资讯、赛事浏览等入口。 | STATIC_INFERENCE |
| 普通用户/参赛者 | 可报名赛事、创建/加入团队、上传材料、查看订单和证件、资源预约。 | CONFIRMED_BY_CODE |
| 指导教师 | 可查看关联学生/团队/证件信息，部分场景参与报名材料。 | STATIC_INFERENCE |
| 赛事管理员 | 维护赛事、报名、团队、赛场、证件、资源、奖项、公示。 | CONFIRMED_BY_CODE |
| 评审专家 | 查看评审任务、材料并提交评分。 | CONFIRMED_BY_CODE |
| 评审秘书 | 控制评审场次对象、扫码解析证件、更新对象状态。 | CONFIRMED_BY_CODE |
| 系统管理员 | 维护用户、角色、菜单、字典、部门、岗位、任务、日志。 | CONFIRMED_BY_CODE |
