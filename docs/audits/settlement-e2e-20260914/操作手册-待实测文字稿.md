## 开始前

**每个团队由一名队员办理，使用办理人本人的账号和银行卡。** 办理期间，其他队员不能进入本队填报；办理人确认完成后，同队成员无需重复填报，也不能再从本队入口填报。

请先准备本人收款信息，并向大赛办理方确认应选择哪个接收单位。整个过程分为：

**填写银行卡 → 确认提供 → 完成填报。**

## 1. 进入本队填报页面

登录原平台，在个人中心打开“我的收款信息v2”，进入“银行卡资料填报”页面。首次办理可先展开“填报须知”。

找到自己的团队，点击 **“申请办理并进入填报”**。如果显示“由您办理中”，点击“继续填报”即可接着办理。若显示“队员办理中”，请与页面显示的办理人联系，由该队员继续操作。

## 2. 使用本人账号登录

填报窗口如要求登录，请使用与原平台办理人一致的本人账号。

- 已经使用过新版账号：按页面提示正常登录。
- 原账号尚未认领：选择 **“原账号 / 密码”**，使用本人的原账号完成登录和认领。
- 提示账号不一致：点击 **“退出当前账号并重新登录”**，再使用本人账号进入。

已登录正确账号时，页面可能直接进入填报，无需重复登录。

## 3. 填写银行卡并保存

按页面分组填写：

| 分组 | 需要填写的内容 |
|---|---|
| 本人信息 | 收款人姓名、收款联系手机号、身份号码 |
| 银行卡信息 | 开户省份、开户城市、银行名称、完整开户支行、银行账号或卡号 |
| 选填内容 | 展开“补充开户行号（选填）”填写 CNAPS 联行号；不清楚可留空 |

请核对银行卡属于收款人本人，开户支行填写完整。**除选填项外，其余内容都需要填写。** 然后点击 **“保存并继续”**。

如弹出安全验证，请按页面提供的方式操作：可使用当前账号已绑定手机收到的验证码；没有绑定手机号时，可使用已设置的 **“当前密码”**。验证通过后，页面会继续刚才的操作，无需重复点击提交。没有弹框时，可直接按页面显示的下一步继续。

**未绑定账号手机号，不等于可以不填“收款联系手机号”。** 收款联系手机号用于结算联系，填写它不会修改账号绑定手机号或实名认证。

点击验证弹框中的“取消”后，本次操作不会继续提交，已填内容仍保留在当前页面。请勿把取消后直接关闭、刷新页面当成保存草稿。

保存成功后，页面会显示“银行卡已保存”和隐藏部分内容的收款摘要。此时请继续下一步。

## 4. 选择指定单位，确认提供

在“确认提供给大赛办理单位”区域：

1. 在“接收单位”中选择 **大赛明确指定的办理单位**；不确定时先联系办理方。
2. 核对单位名称，勾选 **“我同意将收款资料提供给……，用于大赛结算。”** 旁的复选框。
3. 点击 **“确认提供”**，等待页面显示“收款资料已提供”。如再次出现安全验证，按提示完成即可。

选择单位本身不会提供资料。切换单位后，原来的勾选会清空，需要重新核对并勾选。

可展开“谁可以使用这些资料？”了解使用范围：仅所选单位获授权的财务人员可使用当前资料及后续更新。不要因为某个单位出现在列表中，就将资料提供给与本次大赛无关的单位。

## 5. 按引导完成最后确认

提供成功并完成状态核对后，页面会提示 **“还差最后一步：完成团队确认”**，并高亮页面上方的 **“我已完成填报”** 按钮。

**请点击上方“我已完成填报”，等待页面显示“本队已完成填报”及办理人、完成时间。到这一步，才完成本队填报流程。**

如果暂时收起引导，可以点击“查看完成按钮 ↑”再次找到上方按钮。“稍后确认，收起引导”只会关闭提示，不代表已经完成填报。

| 页面显示 | 表示什么 | 下一步 |
|---|---|---|
| 银行卡已保存 | 本人的收款资料已保存 | 选择指定单位、勾选同意并确认提供 |
| 收款资料已提供／待最终确认 | 已向所选单位提供资料 | 点击顶部“我已完成填报” |
| 本队已完成填报／已确认完成 | 办理人已完成团队最终确认 | 等待大赛后续结算通知 |

**“已确认完成”不表示已发奖或已到账，结算进度以大赛通知为准。**

## 中断办理与常见问题

| 遇到的情况 | 如何处理 |
|---|---|
| 入口过期或提示重新进入 | 每次入口有效30分钟。回到原平台点击“继续填报”，或在本队“更多操作”中点击“重新进入填报”。重新进入后按提示核对已保存资料和接收单位。 |
| 中途关掉页面 | 关闭页面不会自动释放本队办理名额。已保存资料可在重新进入后核对；尚未保存的内容需要重新填写。 |
| 顶部“我已完成填报”仍为灰色 | 先确认下方已成功“确认提供”。正在核对时请稍候；如有失败提示，可点击“刷新状态”，或在收款区域“更多操作”中选择“更新已保存状态”后再核对单位。 |
| 找不到接收单位 | 点击“重新加载单位”；仍找不到时联系大赛办理方，不要改选无关单位。 |
| 最终确认前需要修改收款资料 | 点击“修改收款信息”，重新填写完整资料并保存；随后按页面提示核对提供状态，完成顶部最终确认。已确认完成后需要更正的，请联系大赛办理方确认办理方式。 |
| 想停止向某单位提供资料 | 在收款区域“更多操作”的资料提供记录中选择“撤销后续访问”。撤销不删除已提交的历史结算记录，也不删除已合法导出的资料。 |
| 想让其他队员接手 | 先停止填写并关闭其他填报窗口，再在本队“更多操作”中点击“放弃本次办理，释放名额”，按确认框操作。放弃不会删除您已保存或提供的资料。 |
| 没有可查看的获奖队伍记录 | 核对是否登录了正确账号，并联系大赛工作人员确认填报名单。 |

如提示操作未完成，请先核对页面最新状态后再重试；不要仅凭按钮已点击就认为提交成功。
