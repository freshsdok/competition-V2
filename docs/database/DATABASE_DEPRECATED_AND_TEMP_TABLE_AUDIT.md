## 点名类别检查结果

- `offline_v3_*` / `offline_v4_*`：已检出 8 张，建议冻结写入后归档评估。
- `import_*`：测试库当前未检出此前缀表；含 `_import` 的实体/接口更多体现为导入 DTO 或业务导入流程。
- `temp_*`：测试库当前未检出此前缀表。
- `old_*`：测试库当前未检出此前缀表。
- 历史 `site_*`：测试库当前未检出此前缀表。
- `*_copy*`：检出 `component_library_info_copy1`、`wf_copy`，建议先确认来源和访问路径。

## 不建议直接删除的原因

- 可能被报表、导出脚本、Nacos 配置、定时任务或外部 BI 直接访问，静态代码无法覆盖所有调用方。
- 历史导入中间表通常承担审计追溯职责，删除会影响问题复盘。
- Flowable/工作流表由框架维护，即使业务代码不直接引用也可能运行时访问。
